## 2026-01-10: Task 1.6 - Database Schema Design

**Status:** Complete

### What was done:
- Installed Prisma ORM (v7) for type-safe database access
- Designed comprehensive schema for photo management:
  - **User** - Authentication with email, cascading deletes
  - **Photo** - Full metadata including EXIF, S3 keys for 5 resolutions
  - **Tag** - User-defined tags with optional colors
  - **PhotoTag** - Many-to-many photo/tag relationships
  - **Share** - Public gallery links with expiry and view counts
  - **SharePhoto** - Many-to-many share/photo with sort order
- Added database indexes for common queries (userId, takenAt, location)
- Created db.ts module exporting types for app-wide use
- Updated MANUAL_SETUP.md with PostgreSQL setup instructions

### Files created/modified:
